# Automated Fruit Sorting System

A low-cost automated fruit sorting prototype developed using ultrasonic sensing, Arduino-based control, conveyor mechanisms, and servo motor actuation.

## Project Overview

This project focuses on the design and development of a laboratory-scale automated fruit sorting system that classifies fruits according to size.

The system combines sensor technology, embedded control, mechanical transportation, and automated actuation to reduce dependency on manual fruit sorting.

## Project Objectives

- Design and develop an automated conveyor-based fruit sorting system.
- Integrate ultrasonic sensing with microcontroller-based control.
- Measure fruit size using ultrasonic sensors.
- Automate fruit transportation and sorting using motor-controlled mechanisms.
- Evaluate sorting accuracy and operational effectiveness.
- Develop a low-cost prototype suitable for small-scale applications.

## System Architecture

The system consists of three main stages:

1. **Input**
   - HC-SR04 ultrasonic sensors
   - Fruit detection and size measurement

2. **Processing**
   - Arduino Uno
   - Predefined fruit-size classification logic

3. **Output**
   - DC geared motor
   - Conveyor mechanism
   - Servo motors
   - Automated fruit sorting

## Testing & Results

The prototype was tested under controlled laboratory conditions to evaluate sensor detection, conveyor movement, motor operation, and sorting performance.

The system achieved:

- **100% sorting accuracy across 8 controlled test trials**
- Consistent fruit detection and classification
- Stable conveyor and servo motor operation
- Total prototype development cost of approximately **RM267.95**

> Note: The reported 100% accuracy applies to the controlled test trials conducted during this project. The prototype was tested using one type of fruit and was not evaluated under industrial operating conditions.

## Limitations

The current prototype has several limitations:

- Testing was limited to one type of fruit.
- The system primarily classifies fruit based on size.
- The ultrasonic sensing method can be affected by fruit positioning and surface curvature.
- The prototype was evaluated under controlled laboratory conditions.
- The system does not detect fruit colour, ripeness, or internal defects.
- The prototype is not designed for industrial-scale production.

## Future Improvements

Potential improvements include:

- Replacing ultrasonic sensors with higher-precision laser or LiDAR sensors.
- Upgrading the conveyor structure for higher throughput.
- Using higher-torque and more durable actuators.
- Improving the monitoring system using an IoT-based cloud platform.
- Adding additional sensing capabilities for colour, ripeness, and fruit quality.
- Developing a more robust industrial-grade mechanical structure.
